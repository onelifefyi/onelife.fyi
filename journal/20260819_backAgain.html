Back Again

August 19, 2026

I'm back again, hoping to continue working on this site and documenting my journey. Working from my laptop now, trying to keep things simple.

A quick update: console.onelife.fyi and code.onelife.fyi are offline now. RIP to the Mac Mini.

I also removed the cool style I added using Gemini and went back to pure HTML for now.

I don't know what makes the entire web-dev stuff so scary? Every time I've used a web framework, I get intimidated by so many unknown scripts being added to my project.

But then again, that's the exact same for any backend work that I do... adding random packages and black-box code. But for some reason, the backend stuff just doesn't scare me. Who knows.

Even though I want to keep things minimal, I just couldn't stand the bright white background. So, I built a dark mode toggle. It was a fun challenge, I learned how CSS classes can override default styles, and did some actual JS work.

It's pretty cool to learn that a webpage is just a DOM (strange name) tree. With JS, you can grab specific objects off that tree, change their state, or ask them to "listen" for events, and bam, call a function when that happens.

The final thing was local browser storage. I hated that every time I went to a new page, it kept forgetting my choice and switching back to the default theme. Turns out you can have a browser based storage, and can read/write to that.. pretty cool.

Excited for what's next!!
